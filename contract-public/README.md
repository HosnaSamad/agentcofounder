# Public challenge contract

The public development idea is intentionally the only product-specific fixture in this repository.

The generated application is expected to support these observable journeys:

1. Start at `http://localhost:3000` without errors.
2. Add a complete record and show it in the list.
3. Edit and delete an existing record.
4. Narrow the list using the idea's meaningful category or state.
5. Show the requested derived value.
6. Preserve required data across a browser refresh.
7. Record the decision made for the idea's ambiguity in `assumptions`.

Official judging supplies a different idea and private browser journeys. No hidden prompt, selector, threshold, expected copy, or score implementation belongs in this public directory.
